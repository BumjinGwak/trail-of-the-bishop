# 트레일 오브 더 비숍 (Trail of the Bishop)

검은 비숍이 그림자로 만들어진 검은 칸만 밟아 왕관까지 가는 아이소메트릭 퍼즐. (옛 이름: 그늘길)
앞으로 한 칸 걸으면 빛이 다음 자리로 돌고, 뒤로 한 칸 물러나면 이전 자리로 돌아온다.
건물이 빛 반대쪽으로 그림자를 드리우고, 플레이어는 그림자 진 칸만 밟을 수 있다.

## 실행

`index.html` 을 브라우저로 열면 된다. 서버 없이 파일로 바로 동작한다. `index.html#l3` 처럼 열면 3번째 스테이지부터 시작한다.

## 규칙

- 격자 x 는 동쪽, y 는 남쪽. 화면에서는 동쪽이 오른쪽 아래, 남쪽이 왼쪽 아래.
- 빛은 네 자리를 한 걸음마다 시계 방향으로 한 자리씩 돈다: 아침(동쪽 해) → 정오(남쪽 해) → 저녁(서쪽 해) → 밤(북쪽 달) → 다시 아침. 끝이 없다.
- 그림자는 빛 반대쪽 면에서 격자 축을 따라 건물 높이(칸)만큼 일직선으로 뻗는다. 높이 1이면 한 칸, 3이면 세 칸. 여러 건물의 그림자는 합집합이고 건물끼리 붙어 있어도 된다.
- ↑ 앞으로: 빛 +1 자리. ↓ 뒤로: 빛 −1 자리. ← →: 제자리 회전, 빛 유지.
- 플레이어, 깃발, 앞뒤 화살표를 가리는 건물은 반투명으로 그린다.

## 스테이지 설계

1. **그림자 위로** (5×3, 2걸음): 복도 양끝에 높이 3 건물, 가운데 아래에 높이 1. 동쪽으로 두 걸음 걷기만 하면 아침·정오·저녁 그림자가 차례로 발밑에 온다.
2. **길이 열린다** (9×6, 9걸음): 동 4, 북 3, 동 2, 북 1. 앞으로만 걸으면 매 걸음 다음 칸이 그림자가 된다. 직선 구간은 끝 건물의 행 그림자와 옆 건물의 열 그림자가 번갈아 받쳐 준다.
3. **뒤로 걷기** (6×3, 4걸음): 1번 복도에서 왼쪽 건물을 뺀 꼴. 두 번째 칸에서 앞으로는 못 가고, 돌아서서 뒤로 걸어 아침 그림자를 불러와야 한다. 앞으로만으로는 못 푼다.

직선 구간의 한계: 행 그림자는 같은 행의 건물에서만 오고 길이가 높이 이하라, 한 방향 직선은 4~5칸이 최대다. 긴 맵은 짧은 직선을 꺾어 잇는다.

## 레벨 추가

`levels.js` 에 객체를 추가한다.

```js
{
  name: '4. 이름',
  hint: '힌트 문장',
  map: [
    '....G.',   // '.' 바닥, '#' 없음, '1'~'9' 건물 높이, 'S' 시작, 'G' 목표
    'S.2...',
  ],
  startTime: 0,   // 0 아침, 1 정오, 2 저녁, 3 밤
  facing: 'E',
}
```

검증은 헤드리스 Chrome 으로 한다 (Node 불필요):

```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu --dump-dom "file:///C:/Users/d_han/Downloads/shadow-puzzle/tools/check.html"
```

생성기 예:
- 뒤로 걷기가 필요한 맵: `tools/gen.html?seed=5&tries=60000&w=7&h=6&min=5&max=9&back=1&maxback=3&nbmin=3&nbmax=6`
- 앞으로만 걷는 긴 맵(방향 전환 3번 이하): `tools/gen.html?seed=5&tries=60000&w=9&h=6&min=8&max=12&fwdonly=1&maxturns=3&nbmin=6&nbmax=10&voids=0`

결과의 `facing=` 은 첫 걸음이 자연스러운 시작 방향 제안.

## 앞뒤 표시와 사망

- 플레이어 앞 칸은 초록, 뒤 칸은 파랑으로 바닥이 은은하게 깜빡인다. 갈 수 있는지와는 무관하고 방향만 알려 준다. 아래 ↑/↓ 버튼도 같은 색.
- 밝은 땅도 밟을 수 있다. 밟는 순간 록맨식으로 구슬이 사방으로 퍼지며 플레이어가 사라지고(약 0.75초), 곧바로 그 스테이지 처음부터 다시 시작한다. 건물과 구멍은 여전히 막힌다.
- 엔진의 `applyAction` 은 밝은 땅으로의 이동을 `ok: true, fatal: true` 로 돌려주고, 솔버는 `canStand` 만 쓰므로 해법 탐색에는 영향이 없다.

## 아트 방향 (체스 × 모뉴먼트 밸리)

- 설정: 검은 비숍은 평생 한 색 칸만 밟는다. 그림자 칸(검은 칸)만 안전하고, 흰 칸을 밟으면 쓰러진다. 목표는 왕관. 클리어 문구는 "체크메이트", 걸음은 "수".
- 판: 상아색 바닥, 먹색 그림자 칸, 두꺼운 밑판으로 떠 있는 섬처럼. 윤곽선은 거의 없고 면 명암으로만 입체를 낸다.
- 탑: 분홍빛 테라코타 각기둥에 네 모서리 총안(룩). 빛을 향한 면이 밝고, 밤엔 보랏빛으로 식는다. 층 선은 아주 연하게.
- 하늘: 자리별 파스텔 그라데이션(아침 복숭아, 정오 하늘색, 저녁 라벤더→산호, 밤 남색). 밤엔 별이 뜨고 달은 초승달(캔버스를 도려내 하늘이 비친다).
- 비숍: 받침·몸통·목 테·미트라·구슬을 베지어로 그린 실루엣. 검은 칸 위에서도 보이게 상아색 가는 테두리. 미트라의 사선 홈이 바라보는 쪽을 향한다.
- 사망: 바라보던 쪽으로 쓰러지며 흐려지고 먼지가 피어오른다 (DEATH_MS 900).
- 타이포: 제목·시각은 Gowun Batang(세리프), 본문은 Noto Sans KR 300. UI 는 알약형 버튼, 가는 선, 둥근 모서리.
- 색 토큰은 `game.js` 의 `COLORS`/`SKY` 와 `style.css` 의 `:root` 에 모여 있다.

## 스테이지 4와 가시성 조정

- **4. 성벽을 따라** (7×6, 최단 7수, 되감기 2회): 저녁에 시작해 왼쪽 성벽을 따라 북쪽으로. 두 군데에서 한 걸음 물러나야 그림자가 돌아온다. 생성기 `seed=44&w=7&h=6&min=6&max=12&back=1&maxback=5&nbmin=3&nbmax=8&voids=1` 의 #5.
- 가리는 탑은 18% 투명도에 실루엣 한 줄만 남긴다(층 선 생략). 앞·뒤 칸 표시는 탑을 모두 그린 뒤 맨 위에 그려 항상 보인다. 가림 판정 대상은 비숍과 왕관뿐.
- 비숍은 바라보는 쪽으로 약 5° 기울고, 미트라에 그쪽으로 치우친 눈 두 점과 굵은 사선 홈이 있다.

## 첫 시작 인트로

- 주소를 열면(해시 없이, 1스테이지) 약 17초짜리 인트로가 한 번 나온다. 단계마다 1초씩 쉬고 자막은 없다. 해가 돌 때 그림자는 이동 전반부에 바로 바뀐다: 멀리서 줌인(흰 판과 비숍만) → 왕관 등장 → 탑이 위에서 차례로 떨어짐 → 해가 켜지며 궤도와 그림자 등장 → 빛이 한 바퀴 돌며 그림자가 네 번 바뀜 → 게임 시작.
- 아무 키나 누르거나 판/버튼을 클릭하면 건너뛴다. `prefers-reduced-motion` 이면 생략.
- 디버그: `index.html?introAt=2600` 처럼 열면 그 시점부터 시작한다 (스크린샷 확인용).
- 아래 설명 블록과 게임 안의 검은 말풍선(힌트, 사망, 막힘 안내)은 모두 없앴다. 탑이나 구멍으로 가려 하면 그 칸만 잠깐 붉게 깜빡인다.
